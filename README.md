# Rescapincho

## Descripción

Rescapincho es un videojuego desarrollado como proyecto académico para la materia **Taller Conceptual de Videojuegos**, utilizando **GDevelop**.

### Historia

Chispa es un carpincho que vive feliz junto a su familia. Un día, la cazadora **Lady** captura a sus padres y a sus hermanos, dejando a Chispa como el único que logra escapar. A partir de ese momento, deberá recorrer distintos niveles para rescatar a su familia y enfrentar los desafíos que se interponen en su camino.

---

## Mi participación

Durante el desarrollo del proyecto participé en:

- Diseño de niveles.
- Testing funcional.
- Aporte de ideas durante el desarrollo del proyecto.
